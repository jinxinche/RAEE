# Importing evidence from coding agents

This is an **explicit-file importer**, not a watcher. It does not search a home directory or upload logs. Official/observed Codex and Claude session JSONL formats are internal and can change; parsers are best-effort. Only `Bash`-tool results in Claude and recognized command execution events in Codex are supported at present.

```bash
# Choose a specific JSONL file from your own computer (file paths are examples).
raee-lite import-agent --provider claude --file /path/to/session.jsonl
raee-lite import-agent --provider codex  --file /path/to/rollout.jsonl
raee-lite report
```

The importer stores a transcript SHA-256, source filename, line numbers, safe **command family** (e.g. `pytest [arguments redacted]`), and an exit code only if recorded unambiguously. It does **not** store full commands, prompts, model responses or terminal output. Importing a transcript never runs any command. Overlong lines and malformed JSON lines are skipped and counted.

Logs may be partial, tampered with, generated by external tools or belong to a different revision. `RECORDED_ZERO` therefore means *the log contains a zero exit status*; it does NOT establish a current passing test. Unknown status is `UNKNOWN`, never silently treated as a pass.

To explicitly say why a log receipt might relate to a requirement:

```bash
raee-lite add "Login API works"                    # R1
raee-lite expect --for R1 --kind unit               # required scope
raee-lite import-agent --provider claude --file /path/to/session.jsonl
raee-lite link --for R1 --evidence A123456789abc --reason "Pytest included the login test suite"
raee-lite report
```

Substitute a real `A...` id from `.raee/report.json`. A manually linked transcript is **supporting context only**; it does not fulfill the contract. To record a source-bound check, rerun it explicitly:

```bash
raee-lite run --for R1 --kind unit -- python -m pytest tests/test_login.py
```

**Privacy and security:** do not commit `.raee/imports.json`, `.raee/links.json`, or full agent logs to public repositories. Even safe metadata (e.g. source filename and requirement text) may reveal private information. Source filenames are stored; if sensitive, rename the copy first. The import does not try to redact arbitrary private information from files outside its generated metadata.
